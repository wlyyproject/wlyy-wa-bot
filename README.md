
# wlyy-wa-bot

Bot WhatsApp berbasis Node.js menggunakan WhatsBibz 2.1.0.

## Fitur

- `!ping` — membalas `pong`
- `!sticker` — membuat sound sticker dari video yang dikirim atau dibalas
- Menonaktifkan auto-follow channel

## Persyaratan

- Node.js
- FFmpeg dan FFprobe
- Video MP4/MOV dengan suara untuk fitur sound sticker

## Instalasi

```bash
npm install
npm start
```

## Keamanan

- Jangan unggah folder `auth/`.
- Jangan membagikan QR atau kode pairing.
- Gunakan akun WhatsApp yang memang kamu miliki.
- Jangan gunakan bot untuk spam atau mengirim pesan tanpa izin.

## Catatan

Fitur sound sticker masih eksperimental. GitHub hanya menyimpan kode proyek; repository ini belum menjalankan bot 24 jam.
